# Get-InfosPC

Affiche le nom du PC, le fabricant, le modèle, la version de Windows, la RAM et l'espace libre de chaque disque (en rouge sous 10 %).

## Utilisation
```powershell
.\Get-InfosPC.ps1
```

## Notions utilisées
Variables (`$`), `Get-CimInstance`, `Write-Host`, boucle `foreach`, condition `if / else`.
